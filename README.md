# ✅ Form Validation using JavaScript

A simple and effective form validation web app where the user input is validated in real-time before form submission. Helps to prevent invalid data from being sent to server.

## 🚀 Features
- Real-time validation for name, email, password, etc.
- Shows error messages instantly
- Prevents form submission on invalid data
- Clean UI

## 🛠️ Tech Stack
- HTML  
- CSS  
- JavaScript
